STEP 1: CREATE GITHUB REPOSITORY
═════════════════════════════════

1. Go to: https://github.com/new
2. Sign in if needed
3. Fill in:
   - Repository name: Scuba-diving
   - Description: Professional scuba diving website for Havelock Dive Club
   - Public (recommended for portfolio)
   - DO NOT initialize with anything
4. Click "Create repository"
5. Copy the repository URL (you'll need it below)


STEP 2: COPY THESE EXACT COMMANDS
══════════════════════════════════

Replace YOUR_USERNAME with your actual GitHub username.

If your repository URL is: https://github.com/YOUR_USERNAME/Scuba-diving.git
Then run these 4 commands in order:


COMMAND 1 - Navigate to project:
─────────────────────────────────
cd /home/claude/scuba-dive-website


COMMAND 2 - Add GitHub remote:
──────────────────────────────
git remote add origin https://github.com/YOUR_USERNAME/Scuba-diving.git


COMMAND 3 - Rename branch to main:
──────────────────────────────────
git branch -M main


COMMAND 4 - Push to GitHub:
───────────────────────────
git push -u origin main


FULL SEQUENCE (COPY & PASTE):
═════════════════════════════

cd /home/claude/scuba-dive-website
git remote add origin https://github.com/YOUR_USERNAME/Scuba-diving.git

STEP 3: AUTHENTICATE
════════════════════

When prompted for password:
→ Go to https://github.com/settings/tokens
→ Click "Generate new token" → "Generate new token (classic)"
→ Select all permissions
→ Copy the token
→ Paste it when prompted for password


STEP 4: VERIFY SUCCESS
══════════════════════

Check in your terminal:
git branch -vv

Should show: main tracking origin/main ✓

Then visit: https://github.com/YOUR_USERNAME/Scuba-diving

Should see:
✓ All 41 files
✓ Initial commit
✓ README.md displayed
✓ Green checkmark


TROUBLESHOOTING
═══════════════

ERROR: Repository already exists
→ git remote remove origin
→ Then try git remote add... again

ERROR: Authentication failed
→ Make sure your personal access token is correct
→ Or setup SSH key (see GITHUB_PUSH_GUIDE.md)

ERROR: Connection refused
→ Check your internet connection
→ Try again
